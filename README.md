# DRMoonWatch

A single self-contained page that tracks the three DragonRealms moons
(Katamba, Xibar, Yavash), the sun, and the Elanthian calendar - computed live
in your browser from the wall clock, with no server and no network.

- **Live site:** https://moonwatch.dr.elanthia.online/
- **Full documentation:** https://moonwatch.dr.elanthia.online/README.html

Open `index.html` in any browser - that is the entire thing. No server, no
build, no dependencies, no external requests. It works offline.
